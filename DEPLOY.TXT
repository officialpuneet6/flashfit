2. NETLIFY FREE DEPLOY - CUSTOMER SITE
==================================================

For customer website on flashfit.online:

Netlify publish folder should be:

flashfitshop

But IMPORTANT:

Some files are currently shared from project root using ../ paths:

../notification-config.js
../notification-service.js
../flashfit-business-extension.js
../admin-visibility-extension.js

If you deploy only flashfitshop folder, these ../ files will NOT be available.

Before deploy, do ONE of these:

Option A - Recommended:
Copy these files into flashfitshop folder:

notification-config.js
notification-service.js
flashfit-business-extension.js
admin-visibility-extension.js
notification-sw.js

Then update script paths inside flashfitshop HTML files:

../notification-config.js        -> notification-config.js
../notification-service.js       -> notification-service.js
../flashfit-business-extension.js -> flashfit-business-extension.js
../admin-visibility-extension.js -> admin-visibility-extension.js

Also service worker must be available at:

https://flashfit.online/notification-sw.js

Option B:
Deploy full project root and configure redirects carefully.
This is more confusing. Use Option A for simple Netlify deploy.

==================================================
4. CUSTOM DOMAIN SETUP
==================================================

In Netlify:

Site settings -> Domain management -> Add custom domain

Add:
flashfit.online

Also add:
www.flashfit.online

Netlify will show DNS records.

If your domain DNS is managed outside Netlify:

For root domain flashfit.online:
Add A record:

Name: @
Value: 75.2.60.5

For www:
Add CNAME:

Name: www
Value: your-netlify-site-name.netlify.app

Alternative:
Use Netlify DNS nameservers if you want Netlify to manage all DNS.

After DNS update, wait 5 minutes to 24 hours.
